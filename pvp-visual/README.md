# PvP Visual (Fabric, Minecraft 1.21.11)

Клиентский визуальный PvP-мод в стиле Soup Visual. Только визуал: геймплей не меняется, на сервер ставить не нужно.

## Что умеет
- **Бой:** Target HUD, кольцевой прицел, частицы/звук/волна при ударе, бегающее кольцо на цели
- **Мир:** китайская шляпа (размер), круги от прыжка (размер), лента-след (длина)
- **Жемчуг:** траектория броска (лента / точки / пунктир), метка приземления (кольцо / крест / луч), дистанция под прицелом, след за жемчугом, **предсказание для уже летящих жемчугов** (в том числе чужих)
- **Зелья:** траектория взрывного/затяжного зелья в руке, **круг зоны действия** (радиус 4 / 3), **название зелья** под прицелом, предсказание для летящих зелий
- **Руки:** смещение X/Y/Z, размер и наклон рук и предмета от первого лица
- **Цвета:** общий цвет + отдельный цвет для каждой функции (7 тем, включая радугу)
- **Языки:** авто (язык игры), English, Русский, Українська, Deutsch, Polski, Español, Français, Türkçe — можно выбрать прямо в меню (вкладка «Настройки»)

Меню: клавиша **Right Shift** (меняется в Управление → PvP Visual). ЛКМ — переключить/вперёд, ПКМ — назад/сброс, колесо — прокрутка.
Конфиг: `.minecraft/config/pvpvisual.json`.

## Сборка
Нужна Java 21.

    ./gradlew build        # Windows: gradlew.bat build

Готовый мод: `build/libs/pvpvisual-1.0.0.jar` → в папку `mods` (нужны Fabric Loader 0.19.5+ и Fabric API для 1.21.11).
Для запуска из среды разработки: `./gradlew runClient`.

Частицы работают только если в настройках видео «Частицы» = «Все».
